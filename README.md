# PHP Admin Post Manager (Project 3)

This is my third project where I built a blog website using PHP and MySQL. It has an admin panel where you can add, edit, or delete posts and categories. It also handles uploading images using AJAX.

## What it does:
- Admin dashboard to manage everything
- Add, edit, and delete posts (CRUD)
- Create and organize post categories
- Upload images for posts and author profiles via AJAX

## Technologies used:
- PHP
- MySQL
- HTML, CSS, JavaScript (AJAX)
- Run on XAMPP local server

## How to setup on your computer:
1. Download or clone this folder into your `xampp/htdocs/` folder.
2. Open XAMPP and start Apache and MySQL.
3. Create a database in phpMyAdmin and import the SQL file.
4. Change database configurations in `database/db.php` if needed.
5. Open `http://localhost/project-3/` in your browser.
